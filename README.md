# cloth-order

一个手机优先的 Web 原型：通过个人色彩参考、当季衣柜与模拟天气，帮助用户决定今天穿什么。

## 已实现

- Landing 首页与产品说明
- 6 道服装色卡对比题，按选择给出个人色彩方向、推荐色和搭配建议
- 当季衣柜的添加、筛选、删除与进度提示
- 三种模拟天气，以及 3 套每日推荐
- 用户对「就穿这套」的本地反馈记录
- 所有结构化数据仅使用浏览器 `localStorage` 存在当前设备

## 运行

直接用浏览器打开 `index.html` 即可。若使用本地静态服务器，请把当前目录作为站点根目录。

## 原型边界

本原型没有真实账号、云端同步、图片识别、真实天气 API 或应用市场打包。这些应在验证「用户是否会建立小型当季衣柜并持续接受每日推荐」后，再按优先级接入。

## 版本发布

将根目录的 `VERSION` 改为新版本号，在 [CHANGELOG.md](./CHANGELOG.md) 添加以该版本号开头的二级标题和更新内容，再一起推送至 `main`。GitHub Actions 会创建同名标签与 Release，并将该版本的更新内容写入 Release 正文。
