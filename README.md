# cloth-order V0.1

一个手机优先的 Web 原型：通过个人色彩参考、当季衣柜与模拟天气，帮助用户决定今天穿什么。

## 已实现

- Landing 首页与产品说明
- 4 题 Personal Color 初测与「夏季冷柔型」结果页
- 当季衣柜的添加、筛选、删除与进度提示
- 三种模拟天气，以及 3 套每日推荐
- 用户对「就穿这套」的本地反馈记录
- 所有结构化数据仅使用浏览器 `localStorage` 存在当前设备

## 运行

直接用浏览器打开 `index.html` 即可。若使用本地静态服务器，请把当前目录作为站点根目录。

## V0.1 边界

本原型没有真实账号、云端同步、图片识别、真实天气 API 或应用市场打包。这些应在验证「用户是否会建立小型当季衣柜并持续接受每日推荐」后，再按优先级接入。

## 版本发布

更新根目录的 `VERSION` 和 [CHANGELOG.md](./CHANGELOG.md)，再推送至 `main`。GitHub Actions 会自动创建对应标签、Release 与生成式更新说明。
